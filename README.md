# Sistema Hospitalario - DevOps

## Descripción

Sistema Hospitalario utilizado como proyecto práctico para demostrar la aplicación de principios y prácticas DevOps.

El repositorio permite trabajar conceptos como control de versiones, ramas, Pull Requests, integración continua y automatización.

## Objetivo

Aplicar buenas prácticas de DevOps durante el desarrollo de un sistema, utilizando Git y GitHub para controlar los cambios y facilitar la colaboración.

## Tecnologías

- Git
- GitHub
- GitHub Actions
- Markdown
