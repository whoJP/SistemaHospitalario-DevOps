# Arquitectura del Sistema Hospitalario

## Descripción

El Sistema Hospitalario será organizado mediante diferentes componentes que permitan administrar la información relacionada con pacientes, médicos y otros elementos del sistema.

## Componentes principales

- Gestión de pacientes
- Gestión de médicos
- Gestión de usuarios
- Gestión de citas
- Control de acceso

## Enfoque DevOps

El proyecto utilizará Git y GitHub para el control de versiones y la colaboración.

Las modificaciones se desarrollarán mediante ramas y Pull Requests antes de incorporarse a la rama `develop`.
