# Requisitos del Sistema Hospitalario

## Requisitos funcionales

1. El sistema debe permitir registrar pacientes.
2. El sistema debe permitir consultar información de pacientes.
3. El sistema debe permitir registrar médicos.
4. El sistema debe permitir gestionar citas.
5. El sistema debe permitir controlar el acceso de los usuarios.

## Requisitos de desarrollo

El proyecto utilizará Git y GitHub para el control de versiones.

Las nuevas funcionalidades serán desarrolladas mediante ramas independientes y posteriormente integradas mediante Pull Requests.

## Objetivo DevOps

Mantener un proceso de desarrollo organizado, controlado y automatizado mediante prácticas DevOps.
