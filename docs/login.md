# Funcionalidad de Login

## Descripción

La funcionalidad de login permitirá que los usuarios del Sistema Hospitalario puedan acceder al sistema mediante sus credenciales.

## Flujo básico

1. El usuario introduce su usuario.
2. El usuario introduce su contraseña.
3. El sistema valida las credenciales.
4. Si las credenciales son correctas, se permite el acceso.
5. Si las credenciales son incorrectas, se muestra un mensaje de error.

## Desarrollo

Esta funcionalidad se desarrolla en la rama `feature/login` antes de integrarse a `develop`.

La integración se realizará mediante un Pull Request para permitir la revisión de los cambios.
